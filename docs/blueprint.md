# **App Name**: Muse Entrance

## Core Features:

- Logo Display: Display a large, central logo for the music library.
- Title Display: Display the title 'Music Library' prominently below the logo.
- Progress Indication: Provide a subtle progress indicator during the loading process.
- Login Button: Include a primary 'Login' button below the loading area.
- Registration Button: Include a secondary 'Registration' button beside the Login button.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) for a sophisticated and musical feel.
- Background color: Very light gray (#F5F5F5), nearly white.
- Accent color: A slightly lighter shade of indigo (#5C6BC0) for buttons and progress indication, providing contrast but staying within the theme.
- Font pairing: 'Poppins' (sans-serif) for both title and buttons, providing a clean and modern look.
- The logo will take up the top 50% of the loading screen; below that, centered text, then the buttons.
- Implement a subtle, circular loading animation around the logo.
